# USMLE Sorter

Переносит файлы задач USMLE, скачанные из Claude (json и картинки), из папки
«Загрузки» в архив, разложенный по предметам и месяцам.

```
USMLE_Archive/
├── Respiratory/
│   ├── 2026-09/
│   │   └── res-148.png
│   └── 2026-10/
│       ├── res-batch-11.json
│       └── res-147.svg
└── Immunology/
    └── 2026-10/
        └── batch-imm-002.json
```

---

## 1. Установка (один раз)

### Шаг 1. Установите Python

**Windows**
1. Откройте https://www.python.org/downloads/ и нажмите **Download Python**.
2. Запустите установщик и **обязательно поставьте галочку
   «Add python.exe to PATH»** внизу первого окна, затем нажмите **Install Now**.
3. Проверка: нажмите `Win + R`, введите `cmd`, Enter, затем наберите
   `python --version`. Должно появиться что-то вроде `Python 3.13.0`.

**macOS**
Python 3 обычно уже есть. Проверка: откройте «Терминал» и наберите
`python3 --version`. Если команды нет, установите Python с
https://www.python.org/downloads/.

**Linux**
Python 3 почти всегда уже установлен (`python3 --version`).

### Шаг 2. Скачайте программу

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Распакуйте архив в любую удобную папку, например `Документы\usmle-sorter`.

В папке должны лежать файлы:

| Файл              | Что это |
|-------------------|---------|
| `usmle_sorter.py` | сама программа |
| `subjects.json`   | список кодов предметов и названий папок |
| `sort_usmle.bat`  | запуск двойным щелчком (Windows) |
| `sort_usmle.command` | запуск двойным щелчком (macOS) |
| `README.md`       | эта инструкция |

## 2. Запуск

### Самый простой способ (Windows)

Дважды щёлкните **`sort_usmle.bat`**. Откроется чёрное окно, программа
перенесёт файлы и покажет, что куда переложила. Нажмите любую клавишу,
чтобы закрыть окно.

### Самый простой способ (macOS)

Дважды щёлкните **`sort_usmle.command`**. Откроется Терминал, программа
перенесёт файлы и покажет результат.

При первом запуске macOS может написать, что не может проверить разработчика.
Тогда щёлкните по файлу **правой кнопкой → Открыть → Открыть**, и дальше он
будет запускаться обычным двойным щелчком.

Если появляется ошибка «нет прав» (`Permission denied`), один раз выполните
в Терминале из папки с программой: `chmod +x sort_usmle.command`.

### Через командную строку (Windows, macOS, Linux)

1. Откройте командную строку в папке с программой:
   - **Windows:** откройте папку в Проводнике, кликните в адресную строку,
     введите `cmd` и нажмите Enter;
   - **macOS / Linux:** откройте Терминал и перейдите в папку командой
     `cd путь/к/папке`.
2. Введите команду **целиком, одной строкой** (на macOS/Linux вместо
   `python` пишите `python3`):

```bash
python usmle_sorter.py
```

### Рекомендуемый первый запуск — пробный

Чтобы посмотреть, что будет перенесено, **ничего не трогая**:

```bash
python usmle_sorter.py --dry-run
```

Пример вывода:

```
Загрузки: C:\Users\Имя\Downloads
Архив:    C:\Users\Имя\USMLE_Archive
(пробный запуск, файлы не переносятся)
  batch-imm-002.json  ->  Immunology\2026-10\batch-imm-002.json
  res-147.svg  ->  Respiratory\2026-10\res-147.svg
  res-batch-11.json  ->  Respiratory\2026-10\res-batch-11.json
Перенесено: 3, дубликатов удалено: 0
```

Если всё выглядит правильно, запустите без `--dry-run`.

## 3. Все параметры

| Параметр | Что делает |
|----------|------------|
| *(без параметров)* | один раз переносит файлы и завершается |
| `--dry-run` | только показывает, что будет перенесено, ничего не меняет |
| `--watch 30` | работает постоянно и проверяет «Загрузки» каждые 30 секунд; остановить — `Ctrl + C` |
| `--downloads "ПУТЬ"` | другая папка загрузок (по умолчанию `~/Downloads` или `~/Загрузки`) |
| `--archive "ПУТЬ"` | другая папка архива (по умолчанию `~/USMLE_Archive`, т.е. `C:\Users\Имя\USMLE_Archive`) |
| `--include-unknown` | переносить и файлы с кодами, которых нет в `subjects.json` (папка будет названа кодом, например `XYZ`) |

Параметры можно сочетать:

```bash
python usmle_sorter.py --archive "D:\Учёба\USMLE" --watch 60
```

Чтобы `sort_usmle.bat` всегда запускался с нужными параметрами, откройте его
Блокнотом и допишите их в строку с `python`, например:

```
python "%~dp0usmle_sorter.py" --archive "D:\Учёба\USMLE" %*
```

## 4. Какие файлы переносятся

Программа берёт из «Загрузок» только файлы, которые одновременно:

1. имеют формат **`.json`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`**;
2. названы по схеме USMLE-задач:

| Файл                 | Код предмета | Папка |
|----------------------|--------------|-------|
| `res-batch-11.json`  | `res` | Respiratory |
| `batch-imm-002.json` | `imm` | Immunology |
| `res-147.png`        | `res` | Respiratory |
| `res-147.svg`        | `res` | Respiratory |
| `res-147 (1).png`    | `res` | Respiratory (сохранится как `res-147.png`) |
| `neu-001.png`        | `neu` | Neurology |
| `pha_002_x7k21s309.png` | `pha` | Pharmacology |

После номера может идти «хвост» из случайных символов (`_x7k21s309`) — он
сохраняется в имени файла, а предмет и номер определяются по началу.
Разделителем может быть `-` или `_`.

Все остальные файлы в «Загрузках» **не трогаются**.

**Месяц** — это дата, когда файл был скачан (дата изменения файла).

**Повторы:**
- если точно такой же файл уже есть в архиве — копия в «Загрузках» удаляется;
- если имя совпадает, а содержимое другое — файл сохраняется как
  `res-147_2.png`, ничего не перезаписывается.

## 5. Библиотека задач для Claude

После каждого запуска программа обновляет файл **`USMLE_library.md`** в корне
архива (`USMLE_Archive\USMLE_library.md`). В нём:

- **сводка серий** — какие номера уже заняты и какое имя следующее свободное;
- **полный перечень файлов** по предметам и месяцам.

Пример:

```markdown
## Занятые номера

| Серия     | Предмет     | Тип      | Занятые номера | Файлов | Следующее свободное имя |
|-----------|-------------|----------|----------------|--------|-------------------------|
| batch-imm | Immunology  | json     | 1–2            | 2      | batch-imm-003           |
| res       | Respiratory | картинки | 146–147        | 3      | res-148                 |
| res-batch | Respiratory | json     | 1–3, 5, 11–12  | 6      | res-batch-13            |

## Все файлы по папкам

### Respiratory (9)

- **2026-09** (1): res-batch-1.json
- **2026-10** (8): res-146.png, res-147.png, res-147.svg, res-batch-2.json, ...
```

**Как использовать:** перед тем как просить Claude сделать новые задачи,
прикрепите `USMLE_library.md` к сообщению, например:

> Вот моя библиотека задач. Сделай новый батч по respiratory, не повторяя
> существующие названия.

В файле уже есть подсказка для Claude: не использовать занятые номера и
продолжать нумерацию со «следующего свободного».

Библиотека собирается по **фактическому содержимому архива**, поэтому если
вы вручную удалите или переместите файлы, при следующем запуске она это учтёт.
Чтобы просто обновить библиотеку, запустите программу как обычно — даже
если в «Загрузках» нет новых файлов. При `--dry-run` библиотека не меняется.
В режиме `--watch` она обновляется при старте и после каждого переноса.

## 6. Как добавить или переименовать предмет

Откройте `subjects.json` в Блокноте. Каждая строка — это
`"код": "Название папки"`:

```json
{
  "res": "Respiratory",
  "imm": "Immunology",
  "cvs": "Cardiology"
}
```

- Чтобы добавить предмет — допишите строку (не забудьте запятую в конце
  предыдущей строки).
- Чтобы называть папки по-русски — просто замените название:
  `"res": "Дыхательная система"`.

Если программа встретит неизвестный код, она его пропустит и напишет:

```
Пропущены файлы с неизвестными кодами предметов: xyz
  Добавьте их в subjects.json или запустите с --include-unknown
```

## 7. Автозапуск (по желанию)

**Windows — запускать при входе в систему:**
1. Нажмите `Win + R`, введите `shell:startup`, Enter — откроется папка автозагрузки.
2. Правой кнопкой → **Создать → Ярлык**, в поле расположения вставьте
   (подставьте свой путь к программе):
   ```
   pythonw "C:\Users\Имя\Documents\usmle-sorter\usmle_sorter.py" --watch 60
   ```
3. Назовите ярлык, например, `USMLE Sorter`. Теперь программа будет тихо
   работать в фоне и раскладывать файлы каждую минуту.

Чтобы отключить — удалите ярлык из папки автозагрузки.

## 8. Частые проблемы

| Проблема | Решение |
|----------|---------|
| `python` не является внутренней или внешней командой | Python не установлен или не добавлен в PATH — переустановите с галочкой «Add python.exe to PATH» |
| `zsh: command not found: python` (macOS) | пишите `python3` вместо `python`: `python3 usmle_sorter.py` |
| Появилось `>>>` и `SyntaxError: invalid syntax` | вы зашли в интерактивный Python. Выйдите (`Ctrl + D` или `exit()`) и введите команду целиком: `python3 usmle_sorter.py` |
| `Папка загрузок не найдена` | укажите её вручную: `--downloads "C:\Users\Имя\Downloads"` |
| Файл не перенёсся | проверьте, что название подходит под схему из раздела 4, а код есть в `subjects.json`; запустите с `--dry-run` и посмотрите вывод |
| Русские буквы в окне выглядят как «кракозябры» | запускайте через `sort_usmle.bat` — он включает UTF-8 |
