# USMLE Sorter

Переносит файлы задач USMLE, скачанные из Claude, из папки «Загрузки» в архив,
разложенный по предметам и месяцам.

```
USMLE_Archive/
├── Respiratory/
│   ├── 2026-09/
│   │   └── res-148.png
│   └── 2026-10/
│       ├── res-batch-11.json
│       └── res-147.png
└── Immunology/
    └── 2026-10/
        └── batch-imm-002.json
```

## Как распознаются файлы

| Файл                 | Код  | Папка        |
|----------------------|------|--------------|
| `res-batch-11.json`  | res  | Respiratory  |
| `batch-imm-002.json` | imm  | Immunology   |
| `res-147.png`        | res  | Respiratory  |
| `res-147 (1).png`    | res  | Respiratory (сохранится как `res-147.png`) |

- Подходят `.json`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.
- Месяц берётся из даты скачивания файла (дата изменения).
- Остальные файлы в «Загрузках» не трогаются.
- Если такой же файл уже есть в архиве, копия в «Загрузках» удаляется;
  если файл с тем же именем, но другим содержимым — сохраняется как `res-147_2.png`.
- Коды предметов и названия папок — в `subjects.json`. Файлы с неизвестным кодом
  пропускаются (скрипт напишет, какие коды не нашёл). Добавьте код в
  `subjects.json`, например `"cvs": "Cardiology"`, или запустите с `--include-unknown`.

## Запуск

Нужен Python 3.8+ (без дополнительных библиотек).

```bash
# посмотреть, что будет перенесено, ничего не меняя
python usmle_sorter.py --dry-run

# перенести
python usmle_sorter.py

# работать в фоне и проверять папку каждые 30 секунд (Ctrl+C — остановить)
python usmle_sorter.py --watch 30

# свои пути
python usmle_sorter.py --downloads "D:\Загрузки" --archive "D:\USMLE"
```

На Windows можно просто дважды щёлкнуть `sort_usmle.bat`.

По умолчанию: «Загрузки» — `~/Downloads` (или `~/Загрузки`), архив — `~/USMLE_Archive`.
